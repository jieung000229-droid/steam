# 스팀 할인 · 신작 한눈에

스팀 할인 게임과 출시 예정 게임을 장르, 가격, 할인율, 할인 종료일, 출시일, 한글 지원 여부와 함께 보여 주는 사이트예요.
하루 두 번(한국시간 새벽 4시, 오후 4시쯤) 자동으로 갱신돼요. 비용은 들지 않아요.

## 처음 설정하기 (한 번만 하면 돼요)

### 1. GitHub 가입
https://github.com 에서 **Sign up**을 눌러 가입해요. 아이디는 사이트 주소에 들어가니 짧고 쉬운 게 좋아요.

### 2. 저장소(폴더) 만들기
1. 로그인한 뒤 오른쪽 위 **+** → **New repository**를 눌러요.
2. Repository name에 `steam-calendar`처럼 영어로 이름을 적어요.
3. **Public**을 선택해요. (Public이어야 무료로 자동 실행돼요)
4. 아래 **Create repository**를 눌러요.

### 3. 파일 올리기
1. 새 저장소 화면에서 **uploading an existing file** 글자를 눌러요.
2. 받은 압축 파일을 푼 다음, 그 안에 있는 **`docs` 폴더, `scripts` 폴더, `README.md`** 를 화면에 끌어다 놓아요.
3. 맨 아래 **Commit changes**를 눌러요.

### 4. 자동 갱신 설정 파일 만들기
`.github` 폴더는 컴퓨터에서 숨김 폴더라 끌어다 놓기가 잘 안 돼요. 그래서 직접 만들어요.
1. 저장소 화면에서 **Add file** → **Create new file**을 눌러요.
2. 파일 이름 칸에 정확히 `.github/workflows/update.yml` 이라고 적어요. (`/`를 치면 폴더가 자동으로 만들어져요)
3. 압축 파일 안의 **`자동갱신_설정파일.yml`** 을 메모장으로 열어 내용을 전부 복사한 뒤 큰 입력 칸에 붙여 넣어요.
4. 오른쪽 위 **Commit changes...** → 다시 **Commit changes**를 눌러요.

### 5. 사이트 켜기
1. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**로 가요.
2. Source를 **Deploy from a branch**로 두고, Branch를 **main**, 폴더를 **/docs**로 고른 뒤 **Save**를 눌러요.
3. 1~2분 뒤 새로고침하면 위쪽에 사이트 주소가 나와요.
   주소는 `https://내아이디.github.io/steam-calendar/` 형태예요.

### 6. 첫 데이터 채우기
1. 저장소 위쪽 **Actions** 탭으로 가요. (처음이면 초록 버튼으로 사용을 허락해 주세요)
2. 왼쪽 **스팀 데이터 자동 갱신** → 오른쪽 **Run workflow** → 초록 **Run workflow**를 눌러요.
3. 10분 정도 기다리면 초록 체크가 뜨고, 1~2분 뒤 사이트에 게임이 나와요.

이후로는 하루 두 번 알아서 갱신돼요.

## 사이트에서 할 수 있는 것
- **할인 중**: 할인율, 할인 전·후 가격, 할인 종료일(D-day), 장르, 한글 지원, 싱글/멀티/협동
- **출시 예정**: 출시일 순 정렬, 이미 출시된 게임은 한 달 동안 '출시됨'으로 남음
- **출시 달력**: 날짜를 누르면 그날 출시 게임 목록, 날짜 미정 게임은 따로 모아 보기
- **필터**: 장르, 한글/한국어 음성, 싱글/멀티/협동, 체험판, 할인율, 가격, 3일 안에 할인 종료
- **목록 텍스트로 복사**: 지금 보이는 게임 목록을 `이름 | 장르 | 할인 | 종료일 | 한글` 형식으로 복사 (영상 대본 준비용)

## 바꾸고 싶을 때
- **가져올 게임 수**: `scripts/fetch_steam.py` 위쪽의 `MAX_SALE = 150`, `MAX_UPCOMING = 150` 숫자를 바꿔요. 늘릴수록 갱신이 오래 걸려요(게임 100개당 약 3분).
- **사이트 제목**: `docs/index.html`에서 `스팀 <b>할인 · 신작</b> 한눈에` 부분을 바꿔요.
- GitHub 웹에서 파일을 열고 연필(✏️) 아이콘을 누르면 바로 고칠 수 있어요.

## 문제가 생기면
- **Actions에 빨간 X**: 눌러서 오류 내용을 확인해요. 스팀이 잠깐 막은 경우가 많아서 다음 회차에 대부분 저절로 해결돼요.
- **push 권한 오류(403)**: Settings → Actions → General → 맨 아래 Workflow permissions를 **Read and write permissions**로 바꾸고 Save.
- **자동 실행이 멈춤**: 저장소에 60일 동안 아무 활동이 없으면 GitHub가 예약 실행을 멈출 수 있어요. Actions 탭에서 다시 켜 주면 돼요.
- **할인 종료일이 '정보 없음'**: 스팀이 종료일을 공개하지 않은 할인이에요.

데이터 출처: 스팀 상점 공개 정보(비공식). Valve/스팀과 관련 없는 개인 사이트예요.
